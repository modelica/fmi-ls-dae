=== Mathematical Notation

This layered standard uses the same mathematical notation as provided in the FMI 3.0 standard under sub-section https://fmi-standard.org/docs/3.0.2/#mathematical-definitions[Mathematical Notation], with the addition of the symbols introduced here.

.Additional symbols for specific variable types.

|====

|Description

|A vector of real continuous-time variables representing the continuous-time <<AlgebraicVariable, algebraic variables>>.
|[[initial-algebraic,initial algebraic variables]]latexmath:[\mathbf{a}_{\mathit{init}}]
|A vector of real variables representing the <<InitialAlgebraicVariable, initial algebraic variables>>, the unknowns of the initialization problem in DAE mode.
